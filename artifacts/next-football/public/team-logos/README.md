# NEXT Football team logos

Place each team logo here as a PNG using the same normalized name as the official database team name.

Examples:

- `SPARTAK_PLEVEN.png`
- `STANDARD_LIEGE.png`
- `RB_LEIPZIG.png`

Rules:

1. Use uppercase letters.
2. Replace spaces, hyphens and symbols with `_`.
3. Keep the `.png` extension lowercase.
4. A square transparent image is recommended (at least 256×256).

If a logo is missing, the website automatically shows the team's initials instead.
